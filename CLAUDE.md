# Working on ChatBird

- Read `docs/PROGRESS.md` before starting: it says where the project is up to, how things are run,
  and what's next.
- At the end of a session (or when the owner asks), update `docs/PROGRESS.md`: tick finished
  roadmap items, add new decisions with the date, move done ideas out of the parking lot, and
  change "Last updated". Keep it short; never put passwords, keys or tokens in it.
- The Mayfield Phone Repair server runs a tested version (tag `v1.0` and later). Don't change what
  it runs without the owner saying so.
